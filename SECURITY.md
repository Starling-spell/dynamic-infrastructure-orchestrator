# Security

Experimental planning primitive. Do not connect directly to safety-critical equipment.
No custody, token transfers, external execution adapters, or production audit claims.

Report vulnerabilities privately to the repository owner; do not include credentials.
Network owner selects documents and all model configuration. Consensus cannot make a
malicious specification truthful. HTTPS/hash commitments protect bytes, not authority.
The 24-hour deadline prevents old pending plans from applying; documents have no
independently verified publication timestamp.

Terminal plans, owner authorization, network-scoped keys, sealed configurations,
per-step dependency validation, exact parent roots, bounded inputs, and immutable
snapshots are security invariants. Pending consensus failure must not alter model state.
Secrets belong only in encrypted keystores, never source or Git history.
